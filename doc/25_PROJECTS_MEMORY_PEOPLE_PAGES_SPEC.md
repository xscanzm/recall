# 25. 项目、记忆库、人物页施工规格

本文档覆盖三个长期价值页面：项目、记忆库、人物。

## 1. 项目页

### 1.1 页面目标

项目页回答：

- 这个项目最近在推进什么？
- 有哪些未完成事项？
- 做过哪些决策？
- 相关资料和人物有哪些？

### 1.2 项目列表

卡片字段：

- 项目名。
- 最近进展摘要。
- 未收尾数量。
- 最近活跃时间。
- 今日/本周标签。

操作：

- 查看项目。
- 生成项目报告。
- 归档。

### 1.3 项目详情

布局：

```text
项目标题
项目概览
最近时间轴
待收尾
关键决策
相关资料
相关人物
报告
```

项目概览来自 L3 ProjectMemory summary，但要用户化表达。

不要显示 source ids。

### 1.4 项目报告

项目报告结构：

```text
项目当前状态
近期进展
关键决策
未收尾事项
风险
下一步建议
```

## 2. 记忆库

### 2.1 页面目标

帮助用户找回过去。

用户问题示例：

- 上周研究那个工具的结论是什么？
- 我上次和某人聊了什么？
- 某个项目为什么当时这么定？
- 昨天下午我看过哪个网页？

### 2.2 搜索 UI

顶部大搜索框：

```text
搜索过去的工作、资料、决策或人
```

过滤：

- 时间
- 项目
- 类型
- 人物

类型：

- 工作片段
- 任务
- 决策
- 资料
- 项目
- 报告
- 人物

### 2.3 搜索结果卡片

字段：

- 类型标签。
- 标题。
- 摘要。
- 时间。
- 项目。
- 查看来源。

不要像数据库表格。

### 2.4 自然语言问答

如果实现“问回声”，回答必须：

- 只基于检索到的记忆。
- 列出来源。
- 不确定时说明。

## 3. 人物页

### 3.1 页面目标

人物页是用户自己的关系记忆，不是监控别人。

回答：

- 最近和谁有协作？
- 对方和哪些项目有关？
- 我答应过对方什么？
- 对方提过什么需求或意见？

### 3.2 人物列表

字段：

- 姓名。
- 角色/组织。
- 相关项目。
- 最近互动时间。
- 未收尾承诺数。

### 3.3 人物详情

结构：

```text
人物概览
相关项目
最近互动
我答应过的事
对方提到的需求/意见
相关资料
```

### 3.4 隐私

人物页不要给人“监控别人”的感觉。

文案避免：

- 监控
- 追踪
- 行为分析

推荐：

- 相关记忆
- 最近协作
- 提到过的事

## 4. 验收

- 项目页能看到项目进展和待收尾。
- 记忆库能搜索并返回用户可读结果。
- 人物页不带监控语气。
- 所有结果可查看来源。
- 不显示 L0/L1/L2/Fact/Scene。
