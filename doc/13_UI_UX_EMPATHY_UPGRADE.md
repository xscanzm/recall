# 13. UI UX Empathy Upgrade (回声 Recall 界面重构与大升级策划案)

本篇文档是针对 **回声 Recall** 全套界面的重构与升级策划案。

我们拒绝“套壳技术后台”的冰冷感，目标是打造一个**具有呼吸感、生命力，像极简艺术品一样舒适的静默陪伴空间**。通过“感知情境”的动态 AI 驱动力与“渐进式设计”的交互重构，让 Recall 彻底脱胎换骨。

---

## 🎨 视觉升级：从“硬冷像素”到“呼吸纸张”

### 1. 材质与光影：微光流转
*   **底色重塑**：从纯白（`#FFFFFF`）升级为有温度的**天然棉纸色**（`#FBFBFA`），搭配极其微弱的磨砂毛玻璃材质（Mica/Acrylic Effect）。
*   **状态微光（Aura Status）**：
    *   取消生硬的“绿色/橙色/红色”静态小圆点。
    *   在顶部状态栏设计一个**“呼吸微光晕（Aura）”**。
        *   当 Recall 默默守护时，光晕呈现极缓慢的淡绿至淡金的呼吸起伏（10秒一个周期）。
        *   当检测到敏感内容跳过时，光晕像水滴落入湖面一样泛起微澜，随后收敛，没有突兀的弹窗打扰。

### 2. 动效哲学：慢即是快
*   **过渡阻尼**：界面所有卡片的展开、切换，使用带有真实物理阻尼感的 **Spring 动效**。
*   **视差留白**：模块之间留出更宽裕的空气感（Margin），随着用户鼠标的划过，内容呈现极其细腻的 3D 悬浮视差。

### 🚪 Onboarding（新手引导）：从“登记注册”到“相识旅程”
*   **废除“表单地狱”**：不再一上来就展示 Endpoint、Model 和密码输入框。
*   **第一步：感知温情**：展现一段极简流畅的动画，用一两句充满诗意的话解释 Recall 能如何帮你留住指尖流逝的时光。
*   **第二步：渐进配置（Interactive Connection）**：
    *   AI 带着关怀询问：“我可以借用你的视觉模型作为我的眼睛吗？”
    *   输入 Key 的过程设计成**“点亮星空”**的交互，当测试连接成功时，界面上的连线亮起，暗示 AI 获得了理解力，而非单纯的连接成功。

### 🍃 TodayPage（今日页）：从“数据看板”到“心流足迹”
*   **核心理念**：彻底消灭“数据汇报”逻辑。
*   **AI 动态心流包裹（Focus Ring）**：
    *   不再分模块罗列 Task、Decision。
    *   按**“心流时间轴（Focus Blocks）”**呈现。AI 会将高关联的事实和场景打包成一个温暖的卡片，卡片标题由 AI 根据上下文**动态拟定**。
    *   *例如*：下午你连续写了 2 小时代码，AI 动态生成大标题：**“💡 连续两小时的沉浸，你攻克了重构的核心难关”**。

### 🔔 Reminders（回响页）：从“微管理催促”到“温柔的备忘”
*   **极致简化**：卡片上只保留两个自然手势：**“采纳（收进记忆）”** 与 **“忽略（滑开）”**。
*   **悬浮细节**：当用户想要对某条进行精细修正时，悬停在卡片上才会温和地浮现“不再提醒/稍后/编辑”的辅助微标，降噪至极。

### 📝 Reports（日报与复盘）：从“工作汇报”到“今日颂歌”
*   **清零仪式**：日报编辑器的右侧，设计一个温和的 **“Sunset Button（日落安顿）”**。
*   点击后，未完成的任务被轻柔地打上“留给明天”的标记，界面整体色调微微变暖，暗示用户可以关机下班，清空大脑，安享夜晚。

## 🛠️ 重构落地路线图

1.  **第一阶段：Prompt 灵魂接入**（已策划在 `doc/11` 和 `doc/12`）
    *   更换底层的 System Prompt，让大模型输出的 JSON 文本本身自带温度与灵活性。
2.  **第二阶段：全局 CSS 与动效打底**
    *   重塑全局调色盘（以暖白 `#FBFBFA` 与孔雀绿 `#2F8F83` 为主），接入 Spring 动效库。
3.  **第三阶段：TodayPage 与 Onboarding 重构**
    *   重新设计新手引导与今日页的布局，用动态生成的“心流时间轴”取代死板的模块堆砌。
