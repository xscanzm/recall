# 26. 设置与信任中心施工规格

设置和信任中心是 Recall 的信任底座。用户必须清楚 Recall 看什么、存什么、如何调用模型、如何删除。

## 1. 设置页

### 1.1 分区

设置页分区：

1. 模型配置
2. 观察设置
3. 截图保留
4. 黑名单应用
5. 通知
6. 数据管理

## 2. 模型配置

视觉模型和语言模型分开。

字段：

- endpoint
- model
- api key
- temperature optional
- max tokens optional

按钮：

- 测试连接
- 保存
- 删除配置

API Key：

- 输入框 masked。
- 不显示完整 key。
- 不存 SQLite。

## 3. 观察设置

选项：

- 开启/暂停观察。
- 开机后自动恢复观察。
- 只观察活动窗口。

文案：

```text
Recall 只整理当前活动窗口的上下文，不做全屏录屏。
```

## 4. 截图保留

选项：

- 立即删除
- 1 小时
- 6 小时
- 当天
- 3 天
- 7 天

显示：

- 当前缓存大小。
- 清空截图缓存。

文案：

```text
截图用于模型理解，会按你的设置保存在本机。删除截图不会删除已经整理好的文字记忆。
```

## 5. 黑名单应用

支持：

- 应用名。
- 窗口标题关键词。
- 域名关键词。

默认建议：

- 密码管理器。
- 银行支付。
- 医疗证件。

## 6. 通知

选项：

- 应用内提醒：默认开启。
- 桌面通知：默认关闭。
- 日报时间。
- 周报时间。

文案：

```text
桌面通知默认关闭。你可以只在应用内查看提醒。
```

## 7. 数据管理

操作：

- 导出数据。
- 清空截图缓存。
- 忘掉最近 15 分钟。
- 忘掉最近 30 分钟。
- 删除今天数据。
- 清空所有数据。

危险操作必须二次确认。

## 8. 信任中心

信任中心不是法律条款页，要用清楚的人话。

必须包含 5 个卡片：

1. Recall 会看什么
2. Recall 会保存什么
3. 模型 API 如何调用
4. 工作日报如何保护隐私
5. 你如何控制和删除

### 8.1 Recall 会看什么

文案：

```text
开启观察后，Recall 会理解你当前活动窗口的内容，用来整理时间轴、待收尾和报告。
```

### 8.2 Recall 会保存什么

文案：

```text
Recall 会在本机保存结构化记忆，例如工作片段、任务、决策、项目和报告。截图只按你的设置短期保留。
```

### 8.3 模型 API 如何调用

文案：

```text
Recall 使用你配置的视觉模型和语言模型 API。API Key 保存在系统安全存储中，不写入数据库。
```

不要说“绝不经过云端 AI”。

### 8.4 工作日报如何保护隐私

文案：

```text
生成工作日报前，你可以选择哪些时间片段参与生成。未选择的内容不会进入本次日报 prompt。
```

### 8.5 你如何控制

列出：

- 暂停观察。
- 忘掉最近。
- 删除今天。
- 清空截图。
- 导出数据。
- 清空所有数据。

## 9. 验收

- 用户能配置模型。
- 用户能设置截图保留。
- 用户能管理黑名单。
- 用户能关闭桌面通知。
- 用户能清空截图缓存。
- 信任中心不做虚假承诺。
- 信任中心说明工作日报只用选中内容。
