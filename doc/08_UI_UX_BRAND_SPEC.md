# 08. UI UX Brand Spec

## 品牌

中文名：回声  
英文名：Recall

一句话：

> 回声 Recall，把你电脑前流逝的工作上下文，变成可行动的记忆和提醒。

产品气质：

- 安静
- 高级
- 可信
- 主动但不冒犯
- 有一点聪明的生命感

避免：

- 眼睛 logo
- 摄像头 logo
- 监控感
- 截图墙
- 赛博紫蓝渐变
- 过度拟人 AI 头像
- 传统笔记软件信息堆叠

Logo 建议：

- 回环线 + 记忆节点。
- 3 个节点被一条柔和线连接，形成回声/回路感。
- 不使用眼睛、摄像头、大脑。

## 视觉方向

推荐颜色：

- Background: `#F7F6F2`
- Surface: `#FFFFFF`
- Text primary: `#1E2423`
- Text secondary: `#66706D`
- Border: `#E2E0D8`
- Accent green: `#2F8F83`
- Accent amber: `#D9912B`
- Danger: `#C74D3C`

不要让界面单一蓝紫。Recall 应该更像工作助理和记忆系统，不像泛 AI SaaS。

字体：

- Windows: Segoe UI / Microsoft YaHei UI fallback。
- 英文可用 Inter，但不要依赖外网字体。

圆角：

- 卡片 8px。
- 按钮 8px。
- 小标签 999px 可用。

阴影：

- 少用重阴影。
- 用细边框和层级留白表达结构。

## 信息架构

主导航：

1. 今日
2. 提醒
3. 任务
4. 项目
5. 报告
6. 记忆库
7. 设置
8. 信任中心

## App Shell

布局：

- 左侧窄导航栏。
- 顶部状态栏。
- 主内容区。
- 右侧可选上下文栏，用于提醒或来源。

顶部状态栏必须显示：

- 观察中 / 暂停 / 跳过敏感内容 / 模型错误。
- 当前活动 app 简略信息。
- 今日已整理数量。
- 暂停按钮。

## 今日页

今日页是主界面。不要做成聊天页。

模块：

- 今日概览。
- 当前工作主线。
- 应用内提醒。
- 待确认。
- 今日任务。
- 今日决策。
- 日报草稿入口。

今日概览示例：

```text
今天 Recall 识别到 5 段工作场景、18 条事实、6 个待办和 3 个决策。
主要集中在 Recall 产品定义和 AI pipeline 设计。
```

## 提醒页

提醒卡片字段：

- 类型图标。
- 标题。
- 原因。
- 来源数量。
- 置信度标签。
- 操作按钮。

操作：

- 确认。
- 忽略。
- 稍后。
- 标记完成。
- 编辑。
- 不再提醒类似内容。

提醒类型颜色：

- 待确认：amber。
- 任务提醒：green。
- 风险：danger。
- 项目进展：neutral。

## 任务页

任务按状态分组：

- 进行中。
- 未完成。
- 可能已完成。
- 阻塞。
- 待确认。
- 已完成。

每个任务显示：

- 标题。
- 项目。
- 最近证据。
- 状态。
- 优先级。
- 更新时间。

用户操作：

- 标记完成。
- 改项目。
- 编辑标题。
- 删除。
- 查看来源。

## 项目页

项目卡片：

- 项目名。
- 最近进展。
- 未完成任务数。
- 决策数。
- 最后活跃时间。

项目详情：

- 项目主线。
- 最近场景。
- 任务。
- 决策。
- 人物。
- 报告片段。

## 报告页

包含：

- 今日日报。
- 历史日报。
- 周报。
- 重新生成。
- 编辑。
- 复制。

日报编辑器：

- 左侧正文。
- 右侧来源和待确认。
- 条目可删除或编辑。

## 记忆库

搜索输入：

- 支持关键词。
- 后续可支持自然语言问答。

结果类型：

- Fact
- Scene
- Task
- Project
- Decision
- Report

每条结果显示：

- 类型。
- 标题/摘要。
- 时间。
- 项目。
- 来源跳转。

## 设置页

设置模块：

- 模型配置。
- 观察设置。
- 截图保留。
- 通知设置。
- 黑名单。
- 数据导出/清空。

截图保留 UI：

- 单选：立即删除 / 1 小时 / 6 小时 / 当天 / 3 天 / 7 天。
- 显示当前缓存大小。
- 清空截图缓存按钮。

通知设置：

- 应用内提醒：默认开启，不建议关闭。
- 桌面通知：默认关闭。
- 日报时间。
- 周报时间。

## 信任中心

必须以非常清楚的方式展示：

- Recall 看到什么。
- Recall 保存什么。
- 截图保留多久。
- API Key 放在哪里。
- 如何暂停。
- 如何删除。
- 如何导出。

不要用营销话术。用简单、可信的产品语言。

## 空状态

首次未开始观察：

```text
回声还没有开始观察。
配置模型并开启后，它会把今天的工作上下文整理成任务、进展和日报。
```

暂停状态：

```text
已暂停。暂停期间不会采集窗口，也不会调用模型。
```

无报告：

```text
今天还没有足够记忆生成日报。
继续工作一会儿，或手动添加一条记录。
```

## 错误状态

模型错误：

```text
模型连接失败。请检查 endpoint、model 和 API Key。
```

敏感内容跳过：

```text
这段内容看起来比较敏感，Recall 没有采集它。
```

黑名单跳过：

```text
当前应用在黑名单中，Recall 正在安静跳过。
```

## 交互原则

- 用户必须随时能暂停。
- 用户必须随时能删除。
- 用户必须能查看来源。
- AI 生成内容必须可编辑。
- 不要弹太多模态框。
- 不要让用户管理底层 L0/L1/L2/L3 术语。前台用“观察、线索、场景、长期记忆”等更自然的词。

## 前台命名

技术名 -> 用户名：

- Observation -> 观察
- Fact -> 线索
- Scene -> 工作片段
- Memory Object -> 长期记忆
- Proactive Item -> 提醒
- Daily Report -> 日报
