# 15. Timeline Dynamics and Metrics (时光脉络：AI 动态感知与心流指标设计)

在 **回声 Recall** 中，让“每半小时的时间轴”变得灵活、温暖且有生命力，不能仅仅依靠大模型天马行空的文案，而是需要建立一套**优雅的物理指标感知体系（Heartbeat & Flow Metrics）**，作为大模型的“神经末梢”。

大模型基于这半小时内的物理活动特征，去自发感受并涌现出千人千面的状态描述。

---

## 🧭 底层神经末梢：心流物理指标（Flow Metrics）

我们绝不把这些底层数据直接展示给用户（那是极其冰冷且有监控感的）。相反，我们把它们作为 **Observer** 的输入参数：

1.  **活动密度（Activity Density）**：
    *   *定义*：半小时内鼠标点击、键盘敲击的持续时间百分比。
    *   *隐喻*：判定用户是在“疾速输出（High Density）”还是“静默端详（Low Density）”。
2.  **切换频次（App Switching Frequency）**：
    *   *定义*：半小时内不同活动窗口的切换次数。
    *   *隐喻*：高频切换意味着“穿梭寻找、对齐或被打断”；零切换意味着“深度沉浸或单点专注”。
3.  **视线停留焦点（Focus Anchor）**：
    *   *定义*：半小时内停留时间最长的单一应用或网页。
    *   *隐喻*：一堂线上课、一篇长文、一个编辑器或一次设计改稿。
4.  **无物理活动状态（Quiet Interval）**：
    *   *定义*：键盘、鼠标完全静止的时长。
    *   *隐喻*：不要叫“闲置（Idle）”，AI 应该将其感知为“思考时间（Contemplation）”或“离席呼吸”。

---

## 🧠 AI 动态语义生成模型（The Flow Labeling Engine）

在每半小时的节点上，**Observer** 与 **Extractor** 结合上述物理指标，动态生成这一时段的“心流标签（Flow Label）”与“温暖摘要（Warm Summary）”。

### 🪐 场景一：高敲击密度 + 零应用切换（VS Code 停留 30 分钟）
*   **物理指标**：活动密度 88%，切换频次 0，焦点应用：`VS Code`。
*   **AI 神经感知**：用户正处于极高能的连续创作中。
*   **AI 涌现命名**：
    *   *Flow Label*：**「深海沉浸 🌊」**
    *   *Warm Summary*：*“你几乎没有一秒钟将目光移开 VS Code。在寂静中，你用 1200 行代码为 Recall 织成了最坚实的逻辑网。”*

### 🪐 场景二：低敲击密度 + 高应用切换（Chrome、Notion、PowerPoint 频繁穿梭）
*   **物理指标**：活动密度 40%，切换频次 18，焦点：多网页对比。
*   **AI 神经感知**：用户正在做繁杂的素材收集、线索整理或方案对齐。
*   **AI 涌现命名**：
    *   *Flow Label*：**「灵感拼图 ⚡」**
    *   *Warm Summary*：*“你正穿梭在多份方案和文档之间，像一个细心的织网者，试图把散落各处的碎屑拼凑成一张宏大的蓝图。别着急，Recall 已经帮你把它们分好类了。”*

### 🪐 场景三：零活动密度（电脑闲置 25 分钟）
*   **物理指标**：活动密度 0%，Quiet Interval 25分钟。
*   **AI 神经感知**：用户离开了电脑，或者正对着屏幕闭目养神、纸上思考。
*   **AI 涌现命名**：
    *   *Flow Label*：**「留白呼吸 🍃」**
    *   *Warm Summary*：*“屏幕在这半小时里静静地呼吸着。你或许去接了一杯温水，或者正在闭目沉思。给大脑适度的留白，是比前进更重要的力量。”*

## 🎨 前端大升级：时间轴的“呼吸感”渲染

在界面重构上，我们要用 **带有情绪温度的视觉元素** 来渲染这个时间轴，让用户一眼就能感受到自己的“一天状态”：

```text
  [时光脉络 Timeline]
  
  (09:00 - 开始守护)
  
  ●─「深海沉浸」────── (09:00 - 10:30) ──── 🌊
  │  “你心无旁骛地在 VS Code 中写下了重构的底层骨架。”
  │  
  ├─「灵感拼图」────── (10:30 - 11:00) ──── ⚡
  │  “你在文档与设计稿之间高频穿梭。Recall 帮你留存了 3 个关键配色灵感。”
  │  
  ◌─「留白呼吸」────── (11:00 - 11:30) ──── 🍃
  │  “屏幕静静憩息。希望你刚才的那杯咖啡足够香甜。”
```

1.  **卡片大小由“心流浓度”决定（Elastic Card）**：
    *   「深海沉浸」的卡片面积更宽、质感更厚重，甚至背景色会微微泛起温暖的 Accent Green。
    *   「留白呼吸」的卡片设计得极度轻盈、半透明，背景几乎融入棉纸色的底色中，没有任何视觉压迫。
2.  **“不打扰的浮光”交互（Hover Glow）**：
    *   当鼠标轻轻悬停在某个「半小时节点」时，卡片下侧会柔和地散发出微光，向用户浮现当时他复制的内容、或者当时停留时间最长的那张“截图微缩缩略图”（带磨砂模糊，保护隐私）。
